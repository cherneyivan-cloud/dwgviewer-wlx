# DWG Viewer WLX Plugin для Total Commander

Быстрый просмотр DWG-чертежей прямо в Total Commander — без AutoCAD, без
конвертации, без установки CAD-систем.

## Возможности

- DWG R13/R14/R2000/R2004/R2007/R2010/R2013/R2018 (AC1012–AC1032)
- Линии, полилинии (в т.ч. с дугами), окружности, эллипсы, сплайны, 2D/3D-полилинии
- Блоки (INSERT/MINSERT), атрибуты (ATTRIB), внешние ссылки (XREF)
- Штриховки (HATCH), заливки SOLID/TRACE/3DFACE
- Размеры, выноски (LEADER), мультивыноски (MULTILEADER)
- Текст TEXT/MTEXT: кириллица (UTF-8/Windows-1251), поворот, межстрочный
  интервал, перенос строк по ширине, выравнивание по attachment
- Цвета ACI (1–255), truecolor, ByLayer/ByBlock
- Зум колесом, панорамирование, подгонка под окно, эскизы для панели TC

## Требования

- Windows 7 или новее, **x64** (плагин собран как 64-битная DLL)
- Total Commander 9.0 или новее (**64-битная версия**)
- **Права администратора НЕ требуются**

> Плагин 64-битный. В 32-битном Total Commander он не загрузится — для него
> нужна отдельная 32-битная сборка.

## Установка

### Способ 1. Автоматически (рекомендуется)

1. Скачайте `DwgViewer-win64.zip` со страницы
   [Releases](https://github.com/cherneyivan-cloud/dwgviewer-wlx/releases)
   и распакуйте **целиком** в любую папку.
2. Запустите **`install.bat`** (двойной клик).
   Если запускаете из консоли —
   `powershell -ExecutionPolicy Bypass -File install.ps1`.
3. Дождитесь сообщения «Installation complete» и перезапустите Total Commander.
4. Нажмите `F3` на любом `.dwg` — чертёж откроется в просмотрщике.

`install.bat` — это обёртка, которая вызывает `install.ps1` с нужными
параметрами PowerShell. Оба файла должны лежать рядом с
`dwgviewer.wlx` и `libredwg-0.dll`.

### Что делает установщик

Установщик сам выбирает подходящий вариант — вмешательство нужно только в
особых случаях:

| Ситуация | Что произойдёт |
|---|---|
| Папка Total Commander доступна для записи | Плагин копируется в `<TC>\plugins\wlx\DwgViewer\` (классическая схема) |
| Папка TC **недоступна** для записи (например, `C:\Program Files\totalcmd`, нет прав администратора), папки `plugins` может вообще не быть | Плагин копируется в профиль пользователя `%LOCALAPPDATA%\DwgViewer\` и регистрируется в `wincmd.ini` **абсолютным путём**. Создавать папку `plugins` внутри Total Commander не нужно — TC загружает Lister-плагины из любого каталога |
| `wincmd.ini` недоступен для записи | Установщик предложит перенести конфигурацию в `%APPDATA%\Ghisler\wincmd.ini` и подключить её через значение `IniFileName` в `HKCU\Software\Ghisler\Total Commander`. Это тоже не требует прав администратора; исходный файл не изменяется |

Порядок работы скрипта:

1. Находит Total Commander: параметр `-TcDir` → реестр (`InstallDir`) →
   `%COMMANDER_PATH%` → стандартные пути. Если ничего не найдено — открывает
   диалог выбора папки.
2. Определяет настоящий `wincmd.ini`: значение `IniFileName` в реестре →
   `wincmd.ini` рядом с `totalcmd.exe` → `%APPDATA%\Ghisler\wincmd.ini`.
   Реестр имеет приоритет, потому что Total Commander читает путь оттуда.
3. Проверяет, можно ли писать в папку Total Commander (пробным файлом) и
   выбирает каталог для файлов плагина.
4. Копирует `dwgviewer.wlx` и `libredwg-0.dll` в один каталог (оба файла
   обязаны лежать вместе — плагин сам загружает `libredwg-0.dll`).
5. Добавляет запись в `[ListerPlugins]` (`N="полный путь\dwgviewer.wlx"`) и
   `[ListerPlugins64]` (`N=1`). Если плагин уже был зарегистрирован — номер
   переиспользуется, дубликатов не появляется. Перед изменением создаётся
   резервная копия `wincmd.ini.bak`.
6. Проверяет результат, перечитывая файл, и показывает итог.

Кодировка и переводы строк `wincmd.ini` сохраняются (ANSI/CP1251, UTF-8 с BOM
или без, CRLF или LF), остальные настройки не затрагиваются.

### Параметры скрипта

| Параметр | Назначение |
|---|---|
| `-TcDir "D:\TC"` | Указать папку Total Commander вручную |
| `-IniPath "C:\...\wincmd.ini"` | Указать конкретный файл конфигурации |
| `-UserPluginDir "D:\Plugins\DwgViewer"` | Куда ставить плагин, если папка TC недоступна |
| `-FixIni` | Без вопросов перенести недоступный `wincmd.ini` в профиль |
| `-NoIniUpdate` | Только скопировать файлы, конфигурацию не менять |
| `-Uninstall` | Удалить плагин и его регистрацию |
| `-Quiet` | Без интерактивных вопросов (для скриптов) |

Примеры:

```bat
install.bat -TcDir "D:\TotalCommander"
install.bat -Uninstall
powershell -ExecutionPolicy Bypass -File install.ps1 -TcDir "D:\TC" -Quiet
```

### Способ 2. Вручную

1. Скопируйте `dwgviewer.wlx` и `libredwg-0.dll` в **одну** папку, например:
   - `<TC>\plugins\wlx\DwgViewer\` — если папка доступна для записи;
   - `%LOCALAPPDATA%\DwgViewer\` — если прав на папку TC нет
     (создавать `plugins` внутри Total Commander не требуется).
2. Добавьте в `wincmd.ini`:

   ```ini
   [ListerPlugins]
   20="C:\Users\Имя\AppData\Local\DwgViewer\dwgviewer.wlx"

   [ListerPlugins64]
   20=1
   ```

   `20` — любой свободный номер (в `[ListerPlugins64]` тот же номер со
   значением `1` включает плагин для 64-битного TC).

3. Перезапустите Total Commander.

Альтернатива без редактирования файла: «Конфигурация → Настройка → Плагины →
Плагины для просмотра → Настроить → Добавить» и указать путь к
`dwgviewer.wlx`.

### Удаление

```bat
install.bat -Uninstall
```

Скрипт уберёт записи из `wincmd.ini` (с резервной копией) и удалит папку
плагина.

| Действие | Клавиши |
|---|---|
| Подогнать чертёж под окно | `Home`, `F`, `Num5` или двойной клик |
| Зум | колесо мыши |

| Зеркало по горизонтали | `H` |

## Частые проблемы

**Total Commander не найден.** Запустите `install.bat` от имени обычного
пользователя (не «от администратора»): Total Commander должен быть хотя бы раз
запущен, чтобы появилась запись в реестре. Либо укажите папку вручную:
`install.bat -TcDir "D:\TC"`.

**Плагин не открывает DWG.** Проверьте, что Total Commander 64-битный
(`totalcmd64.exe`), и что `dwgviewer.wlx` и `libredwg-0.dll` лежат в одной
папке. После установки Total Commander нужно перезапустить.

**Чертёж открывается другим плагином.** Если установлен другой просмотрщик
DWG, Total Commander выбирает первый подходящий. В открытом просмотрщике
нажмите `1`–`9`, пока не откроется этим плагином (TC запоминает выбор для
расширения), либо измените порядок в «Настройка → Плагины».

**Нужны права администратора?** Нет. Если папка Total Commander защищена от
записи, установщик сам перейдёт на установку в профиль пользователя.
