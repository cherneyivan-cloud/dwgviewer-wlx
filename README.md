# DWG Viewer — плагин просмотра чертежей .dwg для Total Commander (x64)

Lister-плагин (WLX), позволяющий просматривать файлы формата DWG (AutoCAD
и совместимые: R13 … R2018) прямо во встроенном просмотрщике Total Commander
(F3 / Ctrl+Q) и в панели миниатюр.

Плагин использует [LibreDWG](https://www.gnu.org/software/libredwg/)
(GNU GPLv3+) для чтения DWG и GDI (Win32) для отрисовки — не требует
установленного AutoCAD и работает полностью офлайн.

## Возможности

- Открытие DWG R13/R14/R2000/R2004/R2007/R2010/R2013/R2018 (AC1012–AC1032);
- отрисовка основных примитивов: линии, полилинии (в т.ч. с булджами —
  дуговыми сегментами), круги, дуги, эллипсы, сплайны (B-сплайны по Де Буру),
  точкa, 2D/3D-полилинии, SOLID/TRACE/3DFACE (заливка), размеры (упрощённо),
  выноски (LEADER), тексты TEXT/MTEXT (включая коды %%c, %%d, %%p и форматы
  MTEXT); русские подписи: автодетект кодировки (UTF-8 / Windows-1251) и
  минимальный читаемый размер шрифта при любом масштабе;
- **границы штриховок (HATCH)**, заливка сплошных штриховок;
- **каркасы 3D-тел** (3DSOLID/REGION/BODY, проволочные контуры и силуэты);
- **атрибуты блоков (ATTRIB)** и **рамы растровых вставок (IMAGE)**;
- автоконтраст: слишком тёмные элементы отображаются светлыми на чёрном
  фоне (и наоборот — на белом), поэтому «чёрный» текст и линии видны;
- разворачивание блоков (INSERT/MINSERT) с учётом вложенности, поворота
  и масштаба;
- цвета AutoCAD Color Index (1–255), truecolor, ByLayer/ByBlock, учёт
  выключенных/замороженных слоёв;
- режимы линий: сплошная, штриховая, пунктирная и т.п.;
- подгонка под окно при открытии, зум колесом мыши (относительно курсора),
  панорамирование перетаскиванием, кнопки `+`/`-`, двойной клик — подгонка,
  `Home`/`F` — подогнать всё;
- миниатюры в режиме эскизов Total Commander (`ListGetPreviewBitmapW`);
- копирование текущего вида в буфер обмена как изображения (меню просмотрщика);
- печать (диалог печати Windows);
- корректная работа с длинными путями и кириллическими именами файлов.

## Требования

- Windows 7 x64 и новее (Total Commander x64);
- Total Commander 32/64-bit — плагин собран как x64 DLL и регистрируется
  в секции `[ListerPlugins64]`. Для 32-разрядного Total Commander соберите
  плагин отдельно (см. раздел «Сборка»).

## Установка (готовый бинарник в `dist`)

1. Скопируйте папку `dist` целиком или два файла
   `dwgviewer.wlx` и `libredwg-0.dll` в
   `%COMMANDER_PATH%\plugins\wlx\dwgviewer\`.

   > ⚠️ Оба файла должны лежать в одной папке: плагин сам загружает
   > `libredwg-0.dll` из своего каталога во время запуска (Total Commander
   > не добавляет папку плагина в путь поиска DLL). Если библиотеки рядом
   > не окажется — в просмотрщике появится сообщение об этом, а не чертёж.
2. Зарегистрируйте плагин:

   - **Автоматически:** при закрытом Total Commander выполните
     `build\install.ps1` (скрипт сам найдёт `COMMANDER_PATH` и добавит
     записи в `wincmd.ini`).
   - **Вручную:** в Total Commander: «Конфигурация → Настройка → Плагины →
     Плагины для просмотра → Настроить → Добавить» и укажите
     `dwgviewer.wlx` (или измените `wincmd.ini` у себя вручную, добавив
     в `[ListerPlugins]` строку `N=%COMMANDER_PATH%\plugins\wlx\dwgviewer\dwgviewer.wlx`
     и в `[ListerPlugins64]` строку `N=1`, где `N` — следующий свободный номер).

> Если у вас уже установлен другой просмотрщик DWG (например
> `ruDWGPreviewNew`, зарегистрированный раньше по индексу), Total Commander
> будет предлагать первый подходящий плагин. Чтобы использовать этот плагин
> по умолчанию: в открытом просмотрщике нажмите клавишу `1`–`9`, пока DWG
> не откроется этим плагином (TC запоминает выбор для расширения), либо
> поменяйте порядок/определение в «Настройка → Плагины → Плагины для
> просмотра» (отключив другой просмотрщик или убрав его перекрывающее
> определение формата).

3. Нажмите `F3` на любом файле `.dwg` или `Ctrl+Q` для быстрого просмотра.

## Использование

| Действие | Результат |
|---|---|
| Колесо мыши | масштабирование относительно курсора |
| ЛКМ / СКМ / ПКМ + перетаскивание | панорамирование |
| Двойной клик / `Home` / `F` | подогнать чертёж под окно |
| `+` / `-` | зум к центру |
| `V` | зеркало по вертикали (если чертёж «вверх ногами») |
| `H` | зеркало по горизонтали |
| `B` | разворот на 180° |
| Меню просмотрщика → «Копировать» | текущий вид в буфер обмена (картинка) |
| Режим эскизов (Ctrl+Shift+1) | миниатюра DWG |

Настройки хранятся в файле `dwgviewer.ini` рядом с плагином
(создаётся автоматически при первом запуске, если его нет):

```ini
[Options]
Background=0      ; 0 - чёрный фон (как AutoCAD), 1 - белый (для печати/светлых тем)
FlipX=0           ; зеркало по горизонтали (переключается клавишей H)
FlipY=0           ; зеркало по вертикали (переключается клавишей V)
```

## Сборка из исходников

Сборочная цепочка не требует установки Visual Studio:

1. [w64devkit](https://github.com/skeeto/w64devkit) (портативный MinGW-w64 + cmake/ninja);
2. предсобранная `libredwg-0.dll` (win64) и заголовки LibreDWG 0.14;
   оба компонента скачиваются скриптом автоматически.

Запустите:

```
build.bat
build\install.ps1     (при закрытом Total Commander)
```

Шаги `build.bat`:

- при необходимости скачивает и распаковывает тулчейн и библиотеки
  (`build\setup_toolchain.ps1`);
- компилирует `src\aci.c`, `src\draw.c`, `src\model.c`, `src\dwgwlx.c`,
  ресурс `version.rc`;
- линкует `dist\dwgviewer.wlx` (x64 DLL, статический MinGW-runtime);
- копирует в `dist` рантайм `libredwg-0.dll`, `README.md`, `LICENSE`.

Для 32-битной сборки нужно использовать x86-тулчейн w64devkit
(`w64devkit-x86-...`) и x86-версию `libredwg` (`libredwg-0.14-win32.zip`).

## Структура каталога

```
src/
  dwgwlx.c   – экспортируемые функции WLX, окно просмотра, зум/пан,
               буфер обмена, печать, миниатюры
  model.h/c  – загрузка DWG (LibreDWG) и построение модели рисования
  draw.h/c   – трансформации и отрисовка модели в HDC (GDI)
  aci.h/c    – палитра AutoCAD Color Index
  version.rc – ресурс версии
  dwgwlx.def – список экспортов
build/
  setup_toolchain.ps1 – скачивание w64devkit и LibreDWG
  install.ps1         – установка в Total Commander + wincmd.ini
devtest/              – тестовые утилиты (harness, tmodel, test_dwg)
dist/                 – результат сборки (плагин + рантайм + доки)
```

## Интерфейс WLX

Плагин реализует все функции интерфейса WLX:
`ListLoad`, `ListCloseWindow`, `ListGetDetectString`, `ListSearchText`,
`ListSendCommand`, `ListPrint`, `ListNotificationReceived`,
`ListGetPreviewBitmap`, `ListSetDefaultParams` — а также их modern-варианты
с суффиксом `W` (используются 64-разрядным Total Commander).

Строка определения формата:

```
EXT="DWG" | FORCE
```

(любой файл с расширением .dwg; более тщательная проверка заголовка
выполняется в `ListLoadW`)

## Ограничения (версия 1.0)

- Сложные узоры штриховок рисуются как границы; заливка выполняется только для
  сплошных штриховок (SOLID);
- трёхмерные тела отображаются каркасно (проволочные контуры), без затенения;
- растровые изображения (вложенные картинки) показываются рамой вставки,
  без растрового содержимого;
- не отрисовываются: OLE-объекты, WIPEOUT, MLINE, SHAPE и виды (VIEWPORT) —
  их содержимое обычно уже присутствует в модели;
- размеры показываются упрощённо (линии определений + текст размера);
- текст рисуется шрифтом Arial с высотой из чертежа;
- очень большие чертежи могут открываться несколько секунд (парсинг
  выполняется один раз, при открытии).
